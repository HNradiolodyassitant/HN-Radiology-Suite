روش اجرا در macOS
=================

1) پوشه ZIP را Extract کنید.
2) روی فایل START_HN.command دوبار کلیک کنید.
3) اگر macOS اجازه اجرا نداد: روی فایل راست‌کلیک کنید و Open را بزنید.
4) مرورگر باید خودکار باز شود.

اصلاح نسخه 0.2:
- اجرای Vite مستقیماً از مسیر واقعی بسته، بدون استفاده از لینک خراب node_modules/.bin/vite
- نصب تمیز خودکار در صورت ناسازگاری وابستگی‌ها با دستگاه
- حذف خودکار node_modules و package-lock.json فقط در صورت بروز خطا
